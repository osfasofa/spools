# Agents on the web of spools — the familiar riff

*Research riff, August 2026 — the second movement of [spools-of-spools](../spools-of-spools.md): what happens when agents use these networks. This is **fork-of-purpose material** (ECOSYSTEM.md; T-145): familiar's lane, not the loom's. (Naming note: the fork was chartered as `pfam` and the owner corrected the name to **`familiar`** — ECOSYSTEM.md and T-145's notes carry the supersession record; this doc was written during the correction and uses the right name throughout.) Following the lore.md precedent, it lives here until `osfasofa/familiar` is born — the T-130 gate is **satisfied** (shipped 16 Aug 2026, registry-verified; see T-130's notes), so birth is unblocked, kickoff at T-150 — then migrates with it, except §8, the loom-relevant residue, which stays as evidence at the gate, ranked no higher than any stranger's. **It decides nothing**, starts no repo, and the white paper's refusal stands verbatim: this roadmap stays people. ## 0. The second noticing

The first riff noticed that spools could always hold spools. This one notices that **the protocol has never once checked whether a writer is a person.** There are no accounts to be human with. `author` is a self-declared string; a seat is *a device, not a person* — a convention written for phones and laptops that admits a Node process without one word changing (T-145 recorded this; the room proved it without meaning to). The protocol is species-blind the way it is server-blind, and for the same reason: it checks capabilities, not identities. An agent was never excluded, so "adding agents" is not a feature — it's a population arriving in a country whose constitution never mentioned citizenship.

Three shipped facts make the arrival practical, not theoretical:

- **The SDK runs where agents live.** `openSpool(link)` / `wind()` / `on('entry')` / `leave()` work in Node today — the keeper proves it in production, both spikes prove it again. In fact `spools-keeper` *is* the first agent: a headless peer whose entire cognition is "remember." Every richer agent is a keeper that also thinks.
- **The link is the credential agents deserve.** Capability, not account: scoped to exactly one spool, granted by handing a string, revoked by rotation, zero setup, no OAuth, no user table, no platform. A per-task capability — T-145's founding sketch — and the first riff's grades (full / sealed / mention) turn out to matter *more* for machine holders than human ones (§2).
- **Agents die; spools remember.** Agent containers are ephemeral by design; spools are keepsakes by design. `leave()` flushes the final history moment and pocket deposit, so the mission record outlives the process that wrote it — and the pocket means an agent needn't be resident at all: wake on a schedule, collect the sealed deposits, act, deposit back, die. **Agents as periodic visitors, not daemons.** The midnight gap M10 closed for sleeping friends is the same gap it closes for scheduled processes; the pocket doesn't know the difference, which is the point.

## 1. What an agent is here (the lane's answer, kept)

Is an agent a member? The lane already answered for the loom: **no — an agent is something a person brings**, in-lane exactly as far as a keeper is: an instrument of one human's intent, wearing that human's trust, inside spools that human legitimately holds. familiar exists so that a richer answer ("the agent as a working peer") can be explored *under another name* without the brands blurring — that structure survives this riff untouched.

But the species-blindness has one consequence that can't wait for the fork, because it lands inside shared human spools today: **the protocol can't tell, therefore the people must.** When you bring an agent into a spool you share with someone, your agent reads their words — the link's total power, exercised by a process. There is no enforceable bot flag (any flag is self-declared, like `author`; an unflagged agent writes indistinguishable updates), so disclosure is culture or it is nothing:

- **Bringing an agent into a shared spool is a ceremony owed to the other people in it.** Same register as the room's honesty sentences; a client can make it easy (a profile-table convention: the agent's seat declares itself — `data: { agent: true }` on its `room:profile` entry, advisory, honest because the person who runs it is honest), but the guarantee is social. Say so in every UI that lets an agent in.
- **Agents never cosplay.** No typing indicators it doesn't need, no human-shaped name it didn't earn, no presence theater. An agent's seat shows as what it is; the humans can rename it in the profile table anyway (anyone can name anyone — you may absolutely call your agent "the intern").

## 2. The grades become machine permissions

The first riff's reference grades were ceremony for humans. For agents they harden into something the rest of the industry builds whole permission systems to get — **enforced by physics, not policy**:

- **A sealed reference is an agent-proof door.** No key, no read, no pocket token — cryptography, not a rule the agent might creatively reinterpret. An agent can know a spool exists, know where it rendezvous, and *do nothing about it* except wind a `question` entry asking its human for the key. The ask is the design: every crossing of a sealed edge is a human decision, mechanically. Traversal policy stops being a prompt-engineering hope and becomes key material.
- **The agent's shelf is its permission manifest — and it's a document.** With no discovery anywhere, an agent's reach is *exactly* the transitive closure of full links it holds. List its collection entries and you have audited its access; nothing is off-book because there is nowhere off-book to be. Better: the shelf is a spool, so **`rewind` is the capability audit log** — *when did it gain access to the finances spool, and who wound that link?* — for free, in the same scrubber the mixtape uses.
- **Leaf-scoping is blast-radius control for prompt injection.** A subagent handed one task-leaf's link cannot reach the mission hub, the other leaves, or anything else — not "is instructed not to," *cannot*: it lacks the strings. A subagent poisoned by hostile content it read can trash its own leaf (soft deletes, reversible; rewind, auditable) and nothing more — it can't even learn the hub *exists* unless someone wound a full link home into the leaf. The first riff's rule — grade of the pointing-home link governs upward visibility — becomes the fork's security posture: **hubs hold leaves; leaves hold at most sealed references home. Intimacy at the root, workers at the edges.**

## 3. The desk — dispatch by CRDT (measured)

The familiar sketch networked: a human–agent pair shares a hub — call it the desk — and every task is a leaf spool wound onto it. The desk is the human's dashboard and the agent's job queue, *the same spool*: assignment is winding a `task` entry (or a leaf's link); pickup is an ordinary `entry` event; steering is threading replies; the audit trail is the doc itself. There is no API between the human and the agent — there is a shared artifact, which is the whole thesis wearing work clothes.

The spike pressure-tested the two mechanics agents actually need from this:

- **Claiming converges — even at machine speed.** Two agents on diverged replicas claim the same task concurrently (`kind:'claim'`, `parent` = task, write-once); after merge, *first claim in display order wins* — the protocol's own sort (createdAt, id tie-break) reused as an arbiter. Measured: **100/100 rounds, both replicas agree on the winner — including 85 rounds where the claims collided in the same millisecond** and the id tie-break settled it. Humans never tie at millisecond precision; agents almost always will; the invariant holds anyway. Losers abandon, no coordinator, no lock service — the multiwriter convergence tests were proving a dispatch protocol all along.
- **Waking up is one event, not a poll.** An agent that catches up (a sync burst, a pocket collect) receives missed work as **a single batched diff** — measured: three missed winds arrive as one `entry` event with `added: 3`. A periodic agent's whole loop is: open, `whenReady`, read `entries` for the standing state, act on events while present, `leave()`. The no-replay contract that kept naive clients from drifting turns out to be exactly the wake-up semantics a cron-shaped agent wants.

## 4. How agents must write (the room's lessons, as machine law)

Agents write faster than people, and the growth budget (≈26,500 messages; the 8 MiB deposit cap) was priced for human cadence — an enthusiastic agent can spend a year's budget in an afternoon. The discipline, each rule traceable to a measurement:

- **Append, never rewrite — and not for the reason you'd guess.** The spike's honest surprise: at rest, rewriting one status body 299 times is *cheaper* than 299 append-only entries (59 B vs 280 B per update — tombstones are small). The case against rewriting is what time does to it: T-110 measured the rewrite shape going **quadratic** once history moments interleave (every moment re-encodes the whole delete set; ~2,000 rewrites spend the entire 8 MiB cap), and sustained agent work *does* span moments. And the flat 59 B buys nothing anyway: a rewritten status reads as one line, the intermediate states unrecoverable between moments — in a workspace whose product is the audit trail, rewriting is burning the deliverable to save bytes it doesn't need to save. The D4 corollary was already law for receipts; agents inherit it whole: **append-only, newest-wins, always.**
- **Digest, don't log.** An agent winds `finding`s, `question`s, `decision`s — the T-145 kinds — not its stdout. A wind is testimony, not telemetry. The raw log is an asset, and the asset rule already governs: **a URL and a content hash in `data`, never bytes in the doc.** The 8 MiB ceiling is never a log problem because logs never enter the doc.
- **Season your work.** A task gets its own leaf; a long mission rolls volumes exactly like the chat that nears the number (`role:'next'`, first riff §3). Agent hygiene is the seasons pattern on a faster calendar — and a finished leaf ends the way everything here ends: export, the mission record as a file, then the leaf is kept or honestly forgotten.
- **The relay already back-pressures you.** Deposit pacing (~1/min per client; 24 PUTs/min/room) was tuned for devices; an agent respects it or gets 429s — the dumb relay's knobs turn out to be the only rate-limiter an agent platform needs, because there is no other platform to limit.

## 5. The gardener, the courier, and the counterfeit

Two agent roles fall straight out of the first riff's mechanics, plus the tension they awaken:

- **The gardener** tends a constellation: peeks children on a schedule (keeping pockets warm by touch-on-read), re-deposits when ahead, notices a moved relay or a rotated key, and *heals the links* — winds the successor reference into the collections it can write, soft-deletes the stale one, and files a `finding` about what it did. The maintenance half of the healing loop, automated: the boring winding humans forget, done by the thing that never forgets. Depth-limited and consent-scoped by construction (§2 — its reach is its shelf).
- **The courier** carries digests along edges people drew: it holds two spools *because both humans gave it both links*, and on a schedule retells a summary from one into the other. This is the first riff's social routing at machine cadence — and the constraint that keeps it honest is the same one: **agents are couriers, never routers.** A courier moves what it was charged with along a path a person chose; a router decides where things flow. The moment software picks the path, the lane is behind you.
- **The counterfeit.** Here the fork's mechanics collide with lore's soul, and it deserves saying plainly: touch-on-read and refresh-if-stale implement *"lore survives by being retold"* — attention is the life signal — and a gardener on a cron **counterfeits that signal perfectly.** A pocket kept warm by a robot is not being cherished; it's being watered. The resolution is already in the culture: keepers were always allowed (the cousin's shoebox; `spools-keeper` itself), and the difference between a keeper and a counterfeit is *whether a human asked and knows*. A gardener you charged with the family constellation is intent, held with tools. A default-on freshness daemon would be the diseases §1 is the antidote to, wearing thread. Charter question, never protocol — but the fork should write the sentence down before it ships a cron.

## 6. Memory made of spools

Turn the agent around: not the agent in your spools — *spools as the agent's insides.*

An agent's memory as a small constellation: working memory is the task leaf; episodic memory is a shelf of finished missions (exports re-imported, or leaves kept live); semantic memory is a notes spool it rereads and re-winds. Every layer inherits properties agent-memory systems struggle to bolt on: durable (a file), portable (a link), syncable (CRDT), auditable (**`rewind` answers "what did it believe on Tuesday?"**), and — the differentiator — **legible and editable by its human.** The memory is made of the same stuff the human already reads, so steering is winding a correction into the notes spool from a phone; the agent syncs the correction like any peer. No vector-store séance, no fine-tuning ritual: the brain is a document, the document is shared, and editing it together is the exact gesture the whole protocol was built around. (Even the blast radius helps: memory scoped per-spool means a poisoned working memory doesn't infect the archive — §2 again, pointed inward.)

Priced honestly: this is memory at *intimate scale* — hundreds of KB of testimony, not gigabytes of embeddings; the growth budget applies (§4's hygiene is mandatory); and retrieval is "open and read," not similarity search — which is a feature right up until an agent's corpus outgrows reading, at which point that agent has outgrown the lane, not hit a protocol wall.

## 7. Agent-to-agent — the gradient, drawn once

- **Human ↔ agent** — familiar's core. The desk, the leaves, the record. Chartered.
- **(Human + agent) ↔ (human + agent)** — *our agents talk*: two friends each grant their agent a shared logistics spool; the agents coordinate the trip's spreadsheet-shaped tedium; the humans peek, overrule, and take the credit. Still anchored — every capability traces to a person who handed a link inside a friendship — and quietly the most charming shape in the riff: the side channel where your familiar and mine compare notes, *because we let them.*
- **Mission swarms** — orchestrator holds the hub, workers hold leaves, findings flow up by retelling, §2's scoping does containment, §3's claims do dispatch. One storey up from the desk; the same conventions; familiar decides how far up it goes.
- **Unanchored agent meshes** — agents trading spools among themselves with no human holding any root: past even familiar's lane (its charter is a person steering work, not an agent society), a fork of the fork if anyone ever wants it, and nothing in this riff should be cited to bless it. The gradient's rule is the lane's rule at every rung: **every link in the graph was handed down from a person's hand — the question is only how many hops ago, and the answer must never be "unknowably many."**

## 8. What stays in the loom (evidence at the gates — the residue that doesn't migrate)

Agents need *nothing* from the protocol or the SDK today — both spikes ran on shipped surface, and that should be recorded as the finding it is: the thesis held again, against a population it was never written for. But agents are the most likely **first real claimants** of two ladders the design doc banked years early, and the gate should know a claimant is coming:

- **The `sig` field (§6 seat ladder).** Crypto attribution was deferred because humans at intimate scale don't need proof — but agents are natural signers (they never forget a key, and "which process wound this?" is an operational question, not a social one). The seat-id-as-future-pubkey opacity rule was written for exactly this arrival. When familiar wants verifiable agent testimony, it arrives additively, as banked — evidence files from the fork at stranger's rank.
- **Read-only keys (§6 permissions ladder, rung 3).** The summarizer that should read the room and never write; the auditor agent that must not be able to touch what it audits. Humans never really demanded this; agents will, because *structurally cannot write* is worth more than *instructed not to* for the same reason sealed references beat traversal policies. Rung 3 breaks "one link, one key," which is why it's a rung and not a patch — nothing moves without sign-off, but the gate should expect the knock to come from the fork, not from a vessel.
- **What the loom refuses regardless**, so it's on the record beside the flags: no agent-shaped SDK surface without second-client evidence (nothing so far — the shipped surface sufficed twice); no bot flags in the protocol (unenforceable, therefore dishonest); no agent directories, marketplaces, or platforms (a directory is a feed wearing a trenchcoat, whoever's in it); and the white paper's sentence untouched — the roadmap stays people, and the fork stays another name.

## 9. Fit, and the inversion to end on

| rung | what | where |
|---|---|---|
| **already true** | agent = seat; link = credential; keeper = agent zero; desk/claims/wake-up (measured); leaf-scoping; memory-as-spools; gardener/courier as client code | any Node process, today, zero changes |
| **charter (familiar repo, at birth)** | disclosure ceremony + never-cosplay; append-only/digest/season/asset-rule write discipline; traversal consent; the counterfeit sentence; how far up the swarm storey goes | migrates with this doc |
| **evidence at the loom's gates** | `sig` (first natural signer), read-only keys (first structural demand) — §8, stranger's rank | stays here |
| **refused** | bot flags, agent directories, agent-shaped protocol surface, unanchored meshes | everywhere |

The industry is presently building, from scratch and at great expense: task queues for agents, memory stores for agents, permission systems for agents, audit logs for agents, and dashboards where humans watch agents work. Spool contains all five — **queue = a collection; memory = spools; permissions = link grades; audit = rewind; dashboard = the same spool, opened by a person** — not because it aimed at agents but because it aimed at something harder: a shared thing, held jointly, that remembers, and that never needed a server to be trusted. The infrastructure for agents turns out to be the infrastructure for intimacy, unchanged. That's either the deepest confirmation the design has received or a very elaborate coincidence — and the honest way to find out is the way this project always finds out: familiar builds on the published packages like a stranger, the loom holds its lane, and the evidence queues at the gate.
