04 · RULES OF THE SKIN
Skins change tokens, never layout. If a theme needs a structural change, it's not a theme — it's a new client.
Themes are per-device. A theme is your handwriting. It lives in localStorage and syncs nothing.
AA contrast is an acceptance criterion. No theme ships below the floor.
Future skins are additive. Custom assets arrive later as URL + hash pointers — never bytes in the doc.
